# 插件商城 UI 改版设计（PRD）
> 版本：v1.0 ｜ 状态：设计待确认 ｜ 日期：2026-11-04
> 范围：`plugins/marketplace`（面板 `src/Panel.tsx`，单文件 1331 行）
> 需求：①按评分排序 ②tier 支持"不分"（筛选即可，不必分组）③样式布局优化 + 手机端适配
> 数据前提：118 个插件已全部落 `usageTier`（1-10），`index.json` 与 schema 均已就绪

---

## 1. 现状与问题

### 1.1 当前信息架构（痛点）
| 维度 | 现状 | 问题 |
|---|---|---|
| **tier 分组** | 列表强制按 `production → beta → demo` 分组渲染 | 用户不想被等级框死；"不分"应允许、且筛选即足够 |
| **排序** | 仅时间 5 档（default/updated/created） | 无评分排序；缺字段兜底逻辑仅时间可用 |
| **布局** | 全内联样式、固定宽度、无响应式 | 手机端挤成一列、筛选栏换行混乱、详情面板占比大 |
| **视觉** | 深色底 `#1A1A1F`、间距 12px、无卡片层级 | 列表项平铺、可读性一般、无强调元素 |

### 1.2 数据现状（已就绪，本次零数据层改动）
- 118/118 插件有 `usageTier`（1-10），已写入 index.json，schema 已加定义，validate 通过。
- `tier` 为 production/beta/demo 三档字符串；未标注默认 demo（`resolveTier()`，`Panel.tsx:80-84`）。
- 现有排序核心 `sortWithinTier()`（`Panel.tsx:438-460`）可复用、易扩展。

## 2. 目标与非目标

### 2.1 目标
- **G1 评分排序**：列表支持按 `usageTier` 降/升序排序（默认仍 default）。
- **G2 tier 不分组**：新增「不分」模式——tier 退化为**筛选 chip**（不强制分组渲染），列表单列平铺，可配排序。保留"按等级分组"作为可选视图（默认切到"不分"）。
- **G3 视觉升级**：卡片式列表项、筛选栏分区、详情面板重排、统一 8px 栅格与语义色。
- **G4 手机端适配**：≤640px 断点——单列、筛选栏横滑、详情面板全屏/底部抽屉、控件可点面积 ≥40px。

### 2.2 非目标
- 不改数据层 / index.json / schema / 发布脚本。
- 不改已装视图（InstalledView）内部逻辑，仅统一外层容器样式。
- 不做服务端评分聚合、不做下载量排序（无计量）。
- 不引入第三方 UI 库（保持零依赖、内联样式，宿主 WebView 直接消费）。

## 3. 信息架构设计（核心决策）

### 3.1 视图模式：`viewMode: 'group' | 'flat'`
```
视图切换（筛选栏右侧）：
  [ 按等级分组 ]  [ 不分（平铺） ]     ← 默认「不分」
```
- **flat（默认）**：tier 只作为**筛选 chip**（全部/生产/测试/demo），命中后**单列平铺**渲染；排序作用于整个平铺列表。信息流 = "筛选 → 排序 → 平铺列表"。
- **group**：保留现状分组渲染（production → beta → demo 分节），排序在**组内**生效。为兼容既有习惯，保留可选。

### 3.2 排序键扩展
```
type SortKey =
  | 'default'          // 索引原序
  | 'usage-desc'       // 评分最高（usageTier ↓）
  | 'usage-asc'        // 评分最低
  | 'updated-desc' | 'updated-asc'
  | 'created-desc' | 'created-asc'
```
- `sortWithinTier()` 泛化为 `sortList(list, sort)`：flat 模式直接作用于全列表；group 模式作用于组内。
- **缺字段兜底（统一）**：`usageTier` 缺失 → 归"未评分"区固定末尾（不因升降序淹没）；时间缺失同现有行为。
- 排序项显示依据：usage 排序显示「⭐使用评分 N」，时间排序显示「更新于/创建于 …」，default 不显示。

### 3.3 评分徽标（MarketItem 新增）
- 恒显（不限于 usage 排序）：`usageTier` 存在时右上角显示小徽标 `⭐N`；缺失显示灰色 `—`。
- 颜色按分数带：≥8 绿、5-7 琥珀、≤4 灰红。与 tier 徽标并列但独立配色。

## 4. 样式与布局设计

### 4.1 设计 token（内联 `const`，统一语义色）
```ts
const T = {
  bg: '#1A1A1F', card: '#25252B', cardHover: '#2A2A30', line: '#3F3F46',
  text: '#F8F8F8', sub: '#8E8E93', faint: '#6B7280',
  accent: '#3B82F6', green: '#34D399', amber: '#F59E0B', red: '#EF4444',
  radius: 8, gap: 8,
}
```
沿用现有深色主题，只做**层级与间距**升级，不换配色系统（避免与宿主主题脱节）。

### 4.2 布局结构（flat 模式主视图）
```
┌────────────────────────────────────────────┐
│ [搜索框________________________] [↻] [视图▾]│   ← 顶栏：搜索 + 刷新 + 视图切换
├────────────────────────────────────────────┤
│ 源 [官方] [本地×] [+添加源]                  │   ← 源切换条（横滑）
├────────────────────────────────────────────┤
│ 等级 [全部|生产|测试|demo]   分类 [全部|ai|…]│   ← 筛选 chips（可横滑）
│ 排序 [默认▾]   计数：N 个插件               │
├────────────────────────────────────────────┤
│  ⭐9  图片识别    v1.0   [生产][ai]  ⭐9      │   ← 卡片列表（间距 8，hover 提亮）
│  ⭐8  口袋账本    v1.2   [生产][账本]  ⭐8    │
│  …（单列平铺）                              │
├────────────────────────────────────────────┤
│ ── 详情面板（点击项，底部抽屉 / 右侧）─────── │
└────────────────────────────────────────────┘
```

### 4.3 手机端断点（≤640px）
| 元素 | 桌面 | 手机 |
|---|---|---|
| 筛选栏 | 多行换行 | **横向滚动**（`overflowX:auto`，chip 不换行） |
| 卡片 | 2 列可（>900px 用 2 列） | 单列 |
| 详情面板 | 底部占 40% | **全屏覆盖**（`position:fixed; inset:0; z-index`），带关闭 |
| 顶栏 | 搜索 + 视图切换 | 搜索整行 + 视图切换下沉 |
| 控件 | ≥32px | ≥40px 触控区 |

用 `window.matchMedia('(max-width:640px)')` + `useMediaQuery` hook 驱动（无第三方依赖）。

### 4.4 卡片视觉升级（MarketItem）
- 圆角 8、卡片底 `#25252B`、hover `#2A2A30`、选中描边 accent。
- 左侧 icon 槽 36px 圆角 8；标题行：name + v + TierBadge + 评分徽标（右对齐）。
- 描述两行截断（`-webkit-line-clamp:2`），标签 chips 收在底部。
- 评分徽标独立色（绿/琥珀/灰红），一眼可读。

## 5. 交互设计
- 视图切换 flat/group 用 `useState`，不持久化（与现有 sort 一致）。
- 筛选/排序/视图三态互不干扰，组合语义清晰：`filter → sort → (flat|group)`。
- flat 模式无分组标题，仅顶部计数行（`已选 N 个`）。
- 详情面板：点击项展开；手机端全屏抽屉，关闭按钮 + 点遮罩关闭。
- 空态：无匹配 → 居中提示 + 清除筛选按钮。

## 7. 风险与边界
1. **不改数据层**：`usageTier` 已在 index.json，无需回填；自定义源缺字段时评分徽标显示"—"、排序兜底，不报错。
2. **flat 默认 vs group 兼容**：默认切 flat（符合"不需特意分级"诉求）；group 保留为显式选项，用户可切回。
3. **手机端**：面板是宿主 WebView（Tauri/Web），`matchMedia` 可靠；避免横滑与点击冲突（触控区留白）。
4. **内联样式**：无 CSS 文件、无第三方库，改动全在 `Panel.tsx` 单文件，风险集中、易回滚。
