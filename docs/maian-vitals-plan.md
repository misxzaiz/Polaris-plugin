## 1. 机会来源（生态盘点后收敛）

对 `Polaris-plugin` 全量 54 插件盘点后发现：个人财务线（口袋账本/消费账单/常契/守闸/泉府/金匮/票匣/算盘）、生活线（问灶/故人/观止/青囊/chexia）、信息线（订阅/论文/网页/行情雷达）、开发线（relay-devkit/plugin-forge/watchtower）均已饱和；本次初始 12 个候选中「记账」「API 客户端」「车辆台账」在盘点阶段即发现已被占位（部分由并行会话实施中）。

**未被覆盖且需求可证的最强机会：家庭体征记录（血压/血糖/体温/体重）。**

## 2. 需求证据（外部调研，2026-11-01）

1. **医学流程强制「记录」环节**：《中国高血压健康管理规范（2019）》建议初诊/调药期**连续自测家庭血压 7 天**、平稳期每周 1-2 天；2024 修订版《中国高血压防治指南》提倡家庭自测；丁香医生等科普均要求「测量后记录所有结果，复诊时提供给医生」。→ 高频（每天 1-2 次）+ 硬场景（复诊要带记录）。
2. **现有方案不足**：医院发纸质血压记录本（手写、易丢、复诊难分析）；血压记录类 App 用户投诉集中在弹窗广告、会员墙、强制注册/隐私、老人不会用；市面已有产品以「不用注册、没有广告」为核心卖点反向证明这些是真实痛点。
3. **家庭维度空白**：现有产品全部是「单人单设备」维度；「子女替父母记录、全家一册、桌面+手机同录」无主流产品（与青囊立项时同一论证）。
4. **健康数据隐私敏感**：纯本地存储是差异化而非负担。

淘汰理由摘录：番茄/日记/打卡的现有方案足够好（计时器/日记 App 遍地），差异化主要靠「住在工作台里」单点，防御性弱；家底依赖手工录入且与财务线插件重叠。脉案胜在：健康级痛点强度 + 指南背书的硬频率 + 家庭维度真空 + 与青囊（用药）天然成套（药×体征同一护理场景）+ 纯本地零外部依赖（零 API、零密钥、零跨域面）。

**最大不确定性**：用户家庭是否确有慢病监测需求（青囊/金匮的存在是间接信号）。**MVP 验证方式**：安装后一周内是否产生真实记录；**止损**：数据全部在 `maian.*` 键，弃用即弃，无沉没系统。

## 4. 产品定案

- **一句话**：把「爸妈的血压本、血糖记录、每次量的体温体重」变成可对话、会标色、能带走（就诊小结）的家庭体征资产。
- **红线**：只做记录、呈现与提醒配合，**不提供医疗诊断建议**（与青囊同一纪律）；分带阈值是通用参考区间，输出文本必须携带「请遵医嘱」。
- **MVP 范围**：成员档案（身高→BMI 可选）；四类指标（血压 收缩/舒张/心率、血糖 mmol/L×四时点、体温、体重）；红黄分带；近 7/30 天统计与趋势图（手搓 SVG，零依赖）；**就诊小结**（成员+时间段 → 结构化 markdown，复诊可直接给医生）；6 个 MCP 工具对话式记录。
- **明确不做**：诊断/用药建议、个性化目标值、连续血糖仪/血压计蓝牙对接、医患分享云链接、检验报告 OCR（后续候选）。提醒不做后台服务——**复用日晷**（「每天早上 8 点提醒我妈量血压」），脉案专注记录与分析。
- **架构**：零服务进程（对比青囊省掉 service tick）：面板 + MCP 直读写 `cap.kv` 的 `maian.*` 键空间，全部业务口径在 `shared/core.js` 纯函数（三方同源）。家庭量级（千人级记录/年）远低于分块阈值。
- **键空间契约**：`maian.member.<id>`（成员档案）；`maian.day.YYYY-MM-DD`（该日全部记录数组，按 ts 升序）。

## 5. 关键口径（core 单一权威）

- 分带（家庭自测参考，输出必附「请遵医嘱」）：
  - 血压：绿 <130/85；黄 130-139/85-89 或偏低（<90/60）；红 ≥140/90；急 ≥180/120（提示尽快就医）。
  - 血糖（指尖 mmol/L）：空腹 绿 3.9-6.1 / 黄 6.1-7.0 / 红 ≥7.0 或 <3.9；餐后2h 绿 <7.8 / 黄 7.8-11.1 / 红 ≥11.1；随机/睡前同餐后口径。
  - 体温：绿 36.0-37.2；黄 37.3-38.0；红 ≥38.1 或 <35.0。
  - 体重：有身高时按中国 BMI 标准（<18.5 偏瘦黄 / 24-27.9 超重黄 / ≥28 肥胖红），无身高不分带。
- 记录幂等：`id` 可由调用方传入做 upsert（AI 重试不双写）；更新跨日自动迁移日键。
- 输入合法性：血压 sys 60-260、dia 30-160 且 sys>dia；血糖 1.0-40.0；体温 33.0-43.0；体重 2.0-300.0。
