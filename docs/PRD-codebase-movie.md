# PRD: Codebase Movie（代码库电影）

> 将 Git 仓库的演进历史呈现为一部可交互的"电影"。
> 面向开发者、技术团队负责人、开源维护者。

---

## 1. 概述

### 1.1 产品定位

Codebase Movie 是一个 Polaris 插件，将枯燥的 `git log` 转化为沉浸式的**时间线可视化体验**。它把每次提交当作一个"场景"、分支作为"平行剧情线"、贡献者作为"角色"，让用户像看一部电影一样理解代码库的演进。

### 1.2 核心价值

| 场景 | 痛点 | 解决方案 |
|------|------|---------|
| **新人 onboarding** | 阅读代码时不知道"为什么这么写" | 拖拽时间轴看代码在关键提交时的变化，附带 AI 旁白解释 |
| **代码审查** | 不知道某次修改的上下文 | 点击提交，展示当时完整文件状态与关联分支 |
| **项目复盘** | 回顾一个迭代周期的工作难以量化 | 自动生成"本季剧情回顾"——统计 + 关键节点 + 影响分析 |
| **开源项目理解** | 大型项目无从下手 | 从第一个 commit 播放到最新，快速理解项目演进脉络 |

### 1.3 目标用户

- **Agent 开发者/软件工程师** — 需要快速理解陌生代码库
- **技术团队负责人** — 做技术复盘、团队贡献分析
- **开源维护者** — 项目路演、向新贡献者介绍项目
- **学生** — 学习开源项目的最佳实践演进

## 2. 功能规格

### 2.1 核心功能（P0）

#### F1. 时间轴播放器

- 以时间线形式展示所有提交，按时间顺序排列
- 支持**拖拽**（scrub）在时间轴上移动
- 支持**播放/暂停**，自动播放时高亮当前提交
- 播放速度可调（1x / 2x / 4x / 8x）
- 时间轴按天/周/月分桶，根据缩放级别自适应

#### F2. 分支剧情线

- 每条分支渲染为一条独立的"剧情线"，与主时间轴平行
- 合并提交显示为两条线汇合的点
- 分支颜色编码，与常见 git 可视化工具一致
- 可折叠/展开分支线

#### F3. 场景视图（提交详情）

点击一个提交后展示：
- **提交信息**：作者、时间、message、hash
- **文件变更列表**：增/删/改行数，可展开查看 diff
- **AI 旁白**：基于 diff 生成的简短解释（"为什么这次修改"）
- **关联分支**：该提交所属的分支与合并信息
- **前后状态**：可选"前/后"对比视图

#### F4. 角色分析（贡献者视图）

- 每个贡献者作为一个"角色"，展示其活跃时间线
- 贡献统计：提交数、变更行数、修改文件数
- 角色关系图：谁经常和谁一起修改同一文件

### 2.2 增强功能（P1）

#### F5. 关键节点自动识别

AI 自动标记以下关键节点：
- 版本发布（tag）
- 大规模重构（大量文件变更）
- 架构变更（新增/删除关键目录）
- 首次引入某种技术/框架
- 贡献者首次提交

#### F6. 剧本模式

- 自动生成"剧情摘要"：按时间区间概括变更主题
- 可导出为 Markdown 报告（用于周报/复盘）
- 支持注入自定义注释（如"这里是 v2 架构切换点"）

### 2.3 高级功能（P2）

#### F7. 文件演化追踪

- 选中一个文件，查看它在时间轴上的所有变更
- 按时间顺序展示文件内容的演化
- 高亮长期未修改的"僵尸文件"

#### F8. 对比时间点

- 选择两个时间点，生成"期间总览"：新增/删除/重构统计
- 差异热力图：哪些文件改动最频繁

## 3. 技术架构

### 3.1 扩展点利用

| 扩展点 | 用途 |
|--------|------|
| **MCP 工具** | `git log` 解析、diff 分析、统计计算、AI 旁白生成（`analyze_commit`、`get_timeline`、`compare_period`） |
| **ActivityBar 面板** | 主视图——时间轴可视化 + 交互播放器（React + Canvas/SVG） |
| **聊天卡片** | 提交详情卡片、AI 旁白卡片、周报摘要卡片 |
| **后台服务** | 大型仓库的 git 数据预取、增量索引更新 |

### 3.2 数据流

```
┌─────────────┐     ┌──────────────────┐     ┌──────────────┐
│  git 仓库    │────▶│  MCP Server      │────▶│  React Panel  │
│  .git 目录   │     │  (git log/diff)   │     │  (可视化渲染)  │
└─────────────┘     └──────────────────┘     └──────────────┘
                           │                         │
                           ▼                         ▼
                    ┌────────────────┐     ┌──────────────────┐
                    │  AI 旁白生成器  │     │  ChatCard 卡片    │
                    │  (LLM 调用)     │     │  (分享/导出)      │
                    └────────────────┘     └──────────────────┘
```

### 3.3 MCP 工具设计

| 工具名 | 输入 | 输出 |
|--------|------|------|
| `movie.get_timeline` | `branch?`, `since?`, `until?`, `maxCount?` | 提交列表（含 hash、作者、时间、message、文件变更摘要） |
| `movie.get_commit_detail` | `hash` | 完整提交信息 + 文件级 diff |
| `movie.get_branch_topology` | `remote?` | 分支关系图（节点 + 边） |
| `movie.analyze_milestones` | `period?` | 关键节点列表 + AI 摘要 |
| `movie.compare_periods` | `from`, `to` | 期间统计对比 |
| `movie.ai_narrate` | `hash` | AI 生成的旁白文本 |
| `movie.get_contributor_timeline` | `author` | 个人贡献时间线 |

### 3.4 面板组件树

```
MoviePanel
├── TimelineHeader (搜索/过滤/设置)
├── MoviePlayer
│   ├── PlaybackControls (播放/暂停/速度/进度)
│   ├── TimelineCanvas (时间轴主线)
│   │   ├── BranchLanes (分支线)
│   │   ├── CommitNodes (提交节点)
│   │   └── MilestoneMarkers (里程碑标记)
│   └── TimeRuler (时间标尺)
├── SceneDetail (当前选中提交详情)
│   ├── CommitMeta (元信息)
│   ├── FileChangeList (文件变更列表)
│   │   └── FileDiff (内联 diff)
│   ├── AiNarration (AI 旁白)
│   └── BranchContext (分支上下文)
└── BottomSheet (移动端专属底部抽屉)
```

## 4. UI/UX 设计

### 4.1 设计原则

- **沉浸但清晰**：时间轴是主角，信息密度可调
- **移动优先**：所有交互在手机浏览器上可操作
- **渐进式披露**：先展示时间线概览，点击后展开详情
- **暗色模式**：默认暗色，类似影院氛围

### 4.3 关键交互

| 操作 | 交互方式 |
|------|---------|
| **浏览时间轴** | 水平拖拽 / 触摸滑动 |
| **选中提交** | 点击节点 |
| **播放/暂停** | 底部按钮或空格键 |
| **调速** | 按钮切换 |
| **查看 diff** | 点击文件行展开 |
| **搜索** | 按作者/关键词/时间范围 |
| **分享** | 导出为截图或 Markdown 报告 |
| **缩放** | 双指捏合（移动端）/ Ctrl+滚轮（桌面） |

### 4.4 移动端适配要点

- 时间轴默认为**水平可滚动**，高度自适应
- 提交详情以 **BottomSheet** 形式展示，不占用时间轴空间
- 所有按钮保证 ≥44px 触控区域
- 关键操作（播放/暂停/速度）固定在底部，随时可触达
- 横向时充分利用宽度展示更多分支信息

## 5. 数据流与状态

### 5.1 状态管理

```
GitRepository → MCP (git 数据) → Panel State → UI
                                    │
                                    ├── timeline: Commit[]
                                    ├── branches: Branch[]
                                    ├── selectedCommit: Commit | null
                                    ├── playbackSpeed: 1 | 2 | 4 | 8
                                    └── isPlaying: boolean
```

### 5.2 性能考虑

- 大型仓库（>5000 提交）默认只加载最近 500 条，滚动时按需加载
- 分支拓扑从 `git log --graph` 解析，缓存到内存
- diff 仅在用户点击提交时请求，不做预加载
- Canvas 渲染时间轴，节点数 >1000 时自动聚合

## 6. 交付物与验收标准

### 6.1 MVP 范围

| 功能 | 优先级 | 预估复杂度 |
|------|--------|-----------|
| F1 时间轴播放器 | P0 | 高 |
| F2 分支剧情线 | P0 | 中 |
| F3 场景视图（提交详情） | P0 | 中 |
| F4 角色分析 | P1 | 中 |
| F5 关键节点识别 | P1 | 低（依赖 AI） |
| F6 剧本模式 | P2 | 低 |
| F7 文件演化追踪 | P2 | 高 |
| F8 对比时间点 | P2 | 中 |

### 6.2 验收标准

- [ ] 能在任意 git 仓库目录打开时间轴可视化
- [ ] 时间轴可拖拽、可播放，性能流畅（60fps）
- [ ] 分支线正确显示拓扑关系
- [ ] 点击提交显示完整详情 + AI 旁白
- [ ] 移动端浏览器可完整操作，无布局溢出
- [ ] 播放速度切换流畅

## 7. 未来方向（Post-MVP）

- **多人协作模式**：同一仓库多人同时浏览，光标同步
- **PR 时间线**：将 GitHub/GitLab PR 事件集成到时间轴
- **插件化叙事**：允许用户编写自定义"旁白剧本"
- **导出为视频**：将时间轴播放导出为 MP4 视频
- **跨仓库故事线**：在 monorepo 或微服务架构中关联多个仓库

## 8. 附录

### 8.1 竞品参考

| 产品 | 定位 | 差异 |
|------|------|------|
| GitLens | VS Code 内嵌 git 增强 | 偏单次查看，无时间轴叙事 |
| Gource | 独立的代码库可视化工具 | 炫酷但不可交互，无 AI 分析 |
| Observable Plot | 数据可视化库 | 需要编程，非即开即用 |
| CodeSee | 代码地图 | 偏架构图，非时间维度 |

### 8.2 技术风险

| 风险 | 缓解措施 |
|------|---------|
| 大型仓库性能 | 增量加载、Canvas 渲染、Web Worker |
| 分支图解析复杂 | 复用 `git log --graph` 输出，不做 AST 级解析 |
| AI 旁白延迟 | 旁白生成在后台 service 执行，UI 先展示占位 |
| 移动端渲染性能 | 降低节点动画帧率，按视口范围裁剪渲染 |
