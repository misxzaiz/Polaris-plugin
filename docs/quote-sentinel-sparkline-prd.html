你问的「线图」是 当日分时（09:30–15:00 每分钟价）。现状只有一条线，无轴无标注；改进版补齐 时间轴 / 价格轴 / 昨收标注 / 标题 / 末点。
这条线到底是什么？ 横轴 = 当日时间（09:30 开盘 → 11:30 午休 → 13:00 午后 → 15:00 收盘）；纵轴 = 价格；虚线 = 昨收价（涨跌分界）。
不是 按日、不是 K线、不是 多日走势——就是单只标的今天一整天的分时价。
