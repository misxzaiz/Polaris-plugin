# 文档检索 weibian —— 本地文档全文检索与 AI 检索工具

> 文档检索三绝，孔子读《易》翻断编绳——把本地文档「读透串起」的意象。

把散落在本地文件夹里的 **md / txt / PDF / Word(docx) / 网页 / 代码** 变成一条命令可搜、AI 可引用、手机可查的全文索引。**配置一次目录，之后零录入**：后台自动增量扫描，新文件进来自动收录、改动自动跟进。

## 解决什么问题

- 「我确定写过/看过这段内容，但找不到」——Windows 自带搜索弱、Everything 只搜文件名、Obsidian 检索有索引卡死与排序问题；AnyTXT 免费但索引不可控（不能限定目录/类型、不能删索引、资源占用高）。
- 宿主 AI 一直「读过」你的 AI 会话（拾光机）却读不到你的本地文档——文档检索给 AI 4 个工具，对话里说「帮我在文档里找关于 X 的论述」即可。
- 「手机搜电脑文档」此前只有远程桌面这类重方案——文档检索面板三端同读，手机同局域网直连 PC 检索。

## 使用

1. 面板 →「索引」→ 添加要收录的文件夹（有桌面/文档/下载一键建议），保存后服务自动扫描建索引。
2. 面板 →「搜索」：多词按相关性排序；`ext:pdf` / `ext:code` / `dir:子目录` 过滤；点结果预览原文（可分段续读）。
3. AI 对话：`weibian_search`（检索）→ `weibian_read`（读原文引用，仅限索引目录内）；`weibian_status` 看索引状态；`weibian_reindex` 重建。
4. 手机：与电脑同一局域网打开 Polaris，打开文档检索面板即搜（token 鉴权直连）。

## 检索原理（零依赖实现）

- **分词**：ASCII 词元（≥2 字符）+ CJK **unigram+bigram 双层**——bigram 保相邻精度（搜「缓存假象」不会命中「缓存…假象」乱序），unigram 支持单字查询。查询与索引同一函数，零外部分词依赖。
- **排序**：BM25（k1=1.2, b=0.75）+ 文件名全词命中 ×1.5 / 部分命中 ×1.2 / 路径命中 ×1.1。
- **提取**：文本类 BOM→UTF-8 严格→GBK 回退（Windows 老文件友好）；PDF 文字层（pdfjs，扫描件跳过并计数——不做 OCR）；docx 最小 zip 读取器（EOCD+中央目录+inflateRaw）；html 剥脚本样式。
- **增量**：mtime+size 指纹对账；预算化提取（25 文件/轮 × 600ms，5000 文档全量 ≈ 2 分钟不卡盘）；每 10 分钟自动重扫；每文档一个 JSON（`<数据根>/weibian-index/docs/`），正文 ≤128KB 内嵌、超出按需重提取（50 条 LRU）。

## 安全与隐私（硬边界）

- **只索引你显式添加的目录**；默认排除 node_modules / .git / target / dist / AppData 等构建与系统目录、隐藏目录、超限大文件。
- **文件只读**：永不修改/删除/移动任何用户文件。
- **零外网请求**：未申请 network 权限；索引明文存本机数据根，与源文件同信任域。
- **读取越界防护**：`read` 严格限制在索引目录内（resolve 归一防目录穿越 + realpath 复核防符号链接逃逸）。
- 服务端口业务端点一律 token 鉴权（自动下发给面板与 AI）；桌面走 127.0.0.1，手机走局域网（与口袋快传同一安全姿态）。

## 已知限制（如实）

- 单个英文字母/数字（如「a」「5」）不参与检索（词元 ≥2 起）。
- 中英混排（如「React入门」）在语言交界处不建立相邻索引——跨语检索请分开给词。
- 扫描件/图片型 PDF 无文字层，跳过并计数（不做 OCR）；旧版 .doc 不支持。
- OneDrive/网盘占位文件扫描时会按需水合（限速兜底，介意请先设「始终保留在此设备」）。
- 手机检索要求同局域网且电脑端 Polaris 在运行。

## 架构

```
shared/core.js      纯函数核心（分词/BM25/片段/pathRules/设置）——服务/MCP/面板/测试四方同源
service/weibian.js  后台服务：指纹对账 → 预算化提取 → 内存倒排；HTTP API（token）
service/extract.js  提取器：文本(GBK)/PDF(pdfjs)/docx(zip)/html
mcp/server.js       stdio JSON-RPC 4 工具（经 weibian.meta 直连服务）
src/                面板三 Tab（搜索/索引/指南）；kv 走宿主通道，检索走自家服务 HTTP
```
