# STORYBOARD — 《蒲公英》The Dandelion

Logline: Clawd 清晨山坡上偶遇一朵蒲公英，想吹个痛快，却被最后一粒种子"赖"在了头上——种子就在头顶开了花，Clawd 从困惑到心花怒放。

World: 春日山坡。柔和天空奶油蓝 (`sky` 调 cream)， 细腻前山草绿 (sap 调 teal)，远景前山紫罗兰雾感。单一光源右上 (sunglow)。无昼夜变化，色彩随情绪由平静绿意 → 结尾暖金 (花+heart)。
Motif: 那粒"回来"的种子 —— 三次出现：被吹走 (B) → 回弹落鼻尖 (B) → 弹跳落头顶 (C) → 开花 (D payoff)。
Clawd's arc: happy(散步) → excited(发现) → surprised/confused(种子回来) → determined+puff(想吹走) → dizzy(喷嚏误伤) → thinking(摸头) → surprised(水中倒影) → love/happy(花开). 全片表情有 anticipation/overshoot，由 emotions() 驱动。

bpm 92；24fps；总长 21.6s ｜ 1920×1080 ｜ 全镜头纯 2D 手绘、无文字。
