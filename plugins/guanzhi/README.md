# 书影音账本（Guanzhi）— 书影音消费账本

> 常驻工作台的书影音台账：看过的每一步都算数，想看的每一部都会再见到你。

## 解决什么问题

书影音记录的需求真实存在，但现有方案各有结构性缺口：

- **Goodreads 停滞**：被 Amazon 收购后功能长期停滞（「If Goodreads disappeared today, would you care?」等长帖持续吵了多年），用户持续外流到 StoryGraph/Fable 等。
- **豆瓣绑架**：安卓端误点广告强制拉起 App 下载、页Ad面商业化侵蚀记录体验，「逃离豆瓣」是长期话题；主流替代 NeoDB 要先理解联邦宇宙、选实例、注册账号。
- **自托管门槛**：Ryot/Yamtrack/Movary 等自托管追踪器印证了需求，但都要 Docker/服务器；英文元数据生态对中文书影音不友好。
- **记录成本高**：以上全部是「搜索元数据 → 填表单」的流程；记录本身就成了负担，清单死了。

书影音账本的答案：**一句话记账**（AI 从对话提取记录并凭常识补全年份/作者/类型，同体裁同名自动判重转状态）+ **清单被激活**（今晚看什么→从想看清单与进行中给确定性推荐，附口味画像）+ **年报会自己长出来**（纯派生，无需预生成）。纯本地：零网络权限、零后台服务、数据不出设备。

## 怎么用

**聊天里（AI 7 工具，`guanzhi_*`）**：
- 「昨晚看完《流浪地球2》打9分」→ 记账（自动补全 2023/郭帆/科幻，报「今年第 N 部」）
- 「想看《沙丘3》」「开始读《三体》」→ 心愿/进行中（想看 → 开始 → 完成 的状态机）
- 「我看过什么科幻」「上次给《X》打几分」→ 检索（标题/作者/类型/短评模糊）
- 「我今年看了多少电影」「我的平均分」→ 问账（透视 + 年报）
- 「今晚看什么」→ 推荐（先收尾进行中 + 心愿清单躺龄优先 + 逐日轮换，附口味画像）
- 「把这段清单导进来」→ 批量导入（批内 + 账本双重判重，逐条校验）

**面板（四 Tab）**：
- **总览**：今年完成/在进行/评分均值 KPI → 进行中（开得最久在前，先收尾）→ 最近完成 → 想看清单（压得最久在前）→ 记一笔表单
- **藏卷**：搜索 + 体裁/状态/心头好过滤 → 全量记录卡（状态流转/编辑/删除）
- **年报**：年份选择 → 完成数/评分均值/心头好 KPI → 分体裁条形 → 月度 12 柱 → 评分档 → 年度十佳 → 心头好 → 年度最长短评
- **设置**：CSV/JSON 导出（剪贴板）、JSON 导入（判重+逐条校验）、清空数据

## 设计要点

- **一条一键**（`guanzhi.work.<id>`）：规避列表并发覆盖，桌面与手机双端并发后到者胜。
- **状态-日期语义**（唯一权威 `applyStatusDates`）：`wish` 清日期；`active` 补开始日记今天、清陈旧完成日；`done` 缺完成日记今天；`dropped` 原样保留。新建与状态切换共用同一函数，口径不漂移。
- **判重键**：同体裁 + 标题（去空白、忽略大小写）；年份只在双方都有且不同时才区分作品（沙丘1984 ≠ 沙丘2021；一方缺年份视为同作）。导入与账本互判重。
- **推荐确定性**：评分 = min(躺龄天/30, 4) + 体裁定向 +1.5 + 当日盐 jitter（`hash(today+id)`）；同一天重复问结果一致，跨日自然轮换——可解释、无黑盒。
- **导入不做日期臆造**：批量导入 `autoDates=false`，旧记录缺完成日保持缺失，而不是被盖成导入当天。
- **计算唯一权威**：`shared/guanzhi-core.js` 同时被面板 bundle 与 MCP require，口径永不漂移。
- **纯本地**：零网络请求、零后台服务、零跨域面；数据存 cap.kv，桌面与手机 Web 看到同一份。
- **无海报设计**：排版化封面（体裁 emoji + 渐变），不依赖任何外部元数据 API——记录闭环不因外网/反爬/停服而中断。

## 已知边界

- **无海报/评分榜**：不做外部元数据拉取（TMDB/豆瓣），封面为体裁排版卡；后续可选「用户自带 TMDB Key 的可选增强」，不进 MVP。
- **无重看/重读记录**：同一作品只保留一条记录，状态机不表达「第二次看完」；重看感受可更新短评。
- **导入不解析豆瓣 CSV**：豆瓣官方导出 CSV 列结构需实测后适配（见主仓 spec 的后续路线），当前导入格式为书影音账本 JSON（或 AI 整理的数组）。
- **无系统级推送**：清单提醒形态是面板 + AI 随问随答（插件平台能力边界）。
- 评分口径 0-10（一位小数），与豆瓣 5 星、Letterboxd 5 星间需人工换算（×2 / ÷2）。
