# cron-lens · Cron 表达式调试台

写 cron 表达式（task-runner / crontab / CI / ZCode automations）时没有校验和预报——填错只会在「该触发的时候不触发」。本插件把表达式拆开看清楚：

- **解析 + 中文逐字段解释**：每个字段的语义与展开值；`@hourly` 等别名展开；`0,15,30,45` ↔ `*/15` 归一。
- **未来触发预报**：从任意起点算未来 N 次（含星期与 epoch），月长/闰年敏感（`0 0 29 2 *` 自动落 2028-02-29）。
- **坑检测**（vixie/POSIX 语义基准）：
  - 日与周同时受限 = **「或」**（Quartz 是「与」）——跨调度器迁移最常见语义差；
  - 永不触发（`0 0 30 2 *`：2 月无 30 日）与仅闰年触发；
  - `*/n` 起点漂移（`3-59/15` 实际命中 3,18,33,48）、`5/15` 缩写歧义；
  - 6 字段=首位按秒（标准是 5 字段，秒级仅部分调度器支持）、`?` 与 `7` 的归一提示。
- **时刻诊断**：给一个时刻逐字段回答「为什么没触发」，未命中给首因字段与期望集合。

纯本地零外联零 kv；不支持 Quartz 的 L/W/#（明确报错并提示）；触发计算用固定偏移墙钟，不做 DST 推算（如实标注）。

## 形态

- MCP 三工具（`cron_lens_` 前缀）：`explain` / `next` / `match`。
- 面板：表达式输入 + 预设样例 → 字段解释 / 坑警示 / 未来 8 次触发（本机时区）/ 时刻诊断表。

## 引擎

`shared/cron-core.js` 单一权威（MCP 与面板共用，纯函数零依赖）；测试三件套：`test/run-tests.mjs`（core 单测）、`test/mcp-verify.mjs`（stdio JSON-RPC 真实冒烟）、`test/ssr-verify.mjs`（面板 SSR 渲染断言）。
