# 三方分析修正版

## 1. RELAY 布局语义定论（修正）

**RELAY 的布局切换控制的是"请求区与响应区的分栏方向"，不是侧栏位置。**

```
layout='v'（vertical） = 上下分栏
  ┌─────────────────────┐
  │   请求区（req）      │  ← 固定高度 --reqH
  ├─────────────────────┤
  │   分隔条（可拖拽）    │  ← cursor: row-resize
  ├─────────────────────┤
  │   响应区（res）      │
  └─────────────────────┘

layout='h'（horizontal） = 左右分栏
  ┌──────────┬──────────┐
  │ 请求区   │ 响应区    │
  │ (req)    │ (res)     │
  │ 固定宽度  │           │
  │ --reqW   │           │
  └──────────┴──────────┘
  ↑ 分隔条 cursor: col-resize
```

**关键代码证据**：
- `split.style.setProperty('--reqH', ...)` — 上下模式时控制请求区高度
- `split.style.setProperty('--reqW', ...)` — 左右模式时控制请求区宽度
- `split.classList.toggle('h', ui.layout==='h')` — `h` 类名控制 flex-direction
- 按钮文案：`layout==='h'?'⇅ 上下':'⇄ 左右'` — 显示**切换后的目标布局**

**侧栏折叠**是独立控制：`ui.sideCollapsed` + `#main.classList.toggle('collapsed')`，与布局无关。

**我在原型中的错误**：把布局切换错误地等同于"侧栏在工作区的上方/左方"，实际上它控制的是"请求区与响应区之间的分栏方向"。

## 4. 原型修正方案

下一版原型需要修正：

1. **布局切换**：改为控制"请求区与响应区的分栏方向"，不是侧栏位置
   - 按钮在顶栏，文案"上下/左右"（RELAY 语义）
   - 分隔条在请求区和响应区之间，可拖拽
   - 侧栏折叠独立控制

2. **补充 invoke 遗漏功能**：
   - 响应区：业务数据/完整响应双视图、展开层数控制、字体大小、全屏
   - 表格视图：路径刷新按钮、列设置面板（搜索/全选/关键字段）
   - 模板管理：独立页面（非内嵌下拉）
   - 设置页面：服务器配置管理
   - 其他工具入口：JSON 可视化、SQL 格式化

3. **保持已有的正确内容**：
   - RELAY 的环境选择器、cURL 导入、右键菜单、列宽拖拽、tooltip、分组折叠
   - polaris-api 的代码生成、AI 协同、多 Tab、Auth 面板
   - invoke 的双模式、模板选择、动态表单、服务器选择器、全局 Headers
