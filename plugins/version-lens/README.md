# version-lens — semver 版本范围调试台

「为什么 `^0.2.3` 装不到 `0.3.0`」「为什么 beta 装不上」的依赖冲突调试刚需。纯本地零外联零 kv。

## 能力

- **范围解释**：插入符（`^`）/波浪线（`~`）/通配（`x`/`*`）/连字符区间/`||` 并集逐部分展开成比较器，中文说明每个比较器的语义（含上界「-0」精确排他的解释）
- **逐版本判定**：候选版本清单逐一判定 匹配/不匹配/门控拦截，给出原因（放行交集组、首个拒绝比较器）
- **坑检测**：0.x 插入符锁定次版本、0.0.x 锁定补丁、预发布门控（beta/rc 装不上的最高频根因）、`>1.2` 跳段语义、空交集组、`=1.2` 并非精确等于、构建元数据被忽略
- **排序视图**：semver 全序（预发布低于同号正式版、数字标识符按数值比较）

## 语义权威

判定引擎为自研实现，与 **node-semver 7**（npm 实际行为）差分对拍全等（satisfies 1700+ 组矩阵 + compare 全矩阵 + 官方 prerelease 排序链）；语义边界：不做 registry 网络查询、不做 loose 宽松解析、不支持 includePrerelease 变体。

## 形态

- MCP 三工具：`version_lens_explain`（解析+解释+坑）、`version_lens_check`（逐版本判定）、`version_lens_sort`（排序）
- 面板：范围输入 + 版本清单双框 → 解释卡 / 坑卡 / 判定表 / 排序视图，实时计算
