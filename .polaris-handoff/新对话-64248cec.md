## 重构方案

核心是加一条完整的 **PBR 材质管线**：

```
procedural HDRI → PMREMGenerator 预处理 → scene.environment
                              ↓
GLB 加载 → 替换材质为 MeshPhysicalMaterial
          → clearcoat 0.6 + clearcoatRoughness 0.2
          → roughness 0.25（光滑的木漆质感）
          → envMapIntensity 1.2（环境反射强度）
```
